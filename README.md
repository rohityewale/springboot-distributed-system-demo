# springboot-distributed-system-demo

A production-style Spring Boot project to learn and implement distributed systems concepts from scratch.

## Tech Stack

- Java 21
- Spring Boot
- MongoDB Atlas
- Redis
- Apache Kafka
- Podman
- GitHub

## Planned Topics

- Product CRUD
- Redis Cache-Aside Pattern
- Spring Cache (@Cacheable, @CachePut, @CacheEvict)
- Kafka Producer & Consumer
- Outbox Pattern
- Distributed Tracing
- Logging & Monitoring
- Security (JWT)
- Docker/Podman
